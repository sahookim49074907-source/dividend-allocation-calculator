# 계산 정답 시험 (PLAN 작업 4)

가상 사례 5건을 **엑셀로 직접 계산한 정답**과 앱의 계산 결과를 원 단위까지 비교한다. 모두 직접 만든 가상 데이터다.

이 시험은 **계산 실수가 없는지**를 확인한다. 아래 엑셀 수식은 PRD must 1 규칙 2의 끝전 규칙을 그대로 따르므로, 끝전 규칙 자체가 실무와 같은지는 증명하지 않는다 (끝전 규칙은 PRD를 기준으로 확정).

| 파일 | 확인하려는 것 |
|---|---|
| `사례1_기본_나눠떨어짐.csv` | 끝전 없이 딱 나눠떨어지는 기본 계산 |
| `사례2_끝전_동률.csv` | 원 미만이 모두 같을 때 끝전이 목록 앞쪽부터 가는지 |
| `사례3_끝전_크기순.csv` | 끝전이 원 미만이 큰 채권자부터 가는지 |
| `사례4_극단값_1원채권.csv` | 1원짜리 채권처럼 아주 작은 금액이 섞였을 때 |
| `사례5_채권자20명.csv` | 실제와 비슷한 20명 규모 |

## 1. 엑셀로 정답 계산하기

각 CSV를 엑셀로 열면 1행에 배당재원, 2행에 머리글, 3행부터 채권자가 있다. 채권자가 3행부터 `n`행까지라면, 빈 열(F열부터)에 아래 수식을 넣고 아래로 채운다.

| 열 | 뜻 | 3행에 넣을 수식 |
|---|---|---|
| F | 원 미만 버린 배당금 | `=ROUNDDOWN($B$1*C3/SUM($C$3:$C$n),0)` |
| G | 버린 원 미만 부분 | `=$B$1*C3/SUM($C$3:$C$n)-F3` |
| H | 끝전 받는 순서 (같으면 앞 사람 먼저) | `=RANK(G3,$G$3:$G$n,0)+COUNTIF($G$3:G3,G3)-1` |
| I | 남은 끝전 (모든 행 같은 값) | `=$B$1-SUM($F$3:$F$n)` |
| D | **엑셀정답** | `=F3+IF(H3<=I3,1,0)` |

수식의 `n`은 마지막 행 번호로 바꾼다 (예: 사례1은 5, 사례5는 22).

## 2. 저장하기

1. D열(엑셀정답)을 복사한 뒤 **값만 붙여넣기**로 바꾼다.
2. F~I열을 지운다.
3. **CSV UTF-8 (쉼표로 분리)** 형식으로 같은 이름에 덮어써 저장한다.

숫자에 `1,000,000`처럼 쉼표 서식이 있어도 괜찮다.

## 3. 비교하기

`my-app` 폴더에서 아래 명령을 실행한다.

```bash
node --no-warnings test-cases/check.mjs
```

사례마다 ✅(일치) 또는 ❌(불일치·빈칸)가 나온다. 불일치하면 몇 번 행이 앱과 엑셀에서 각각 얼마인지 보여준다. 5건 모두 ✅이면 3번 목표("5건 모두 원 단위까지 일치")를 달성한 것이다.
